MASTER DEVELOPMENT PROMPT

Cinematic Video Presentation of the Existing 3D Fuel Depot Digital Twin

You are an experienced senior Three.js/WebGL developer, real-time 3D visualization engineer, cinematic camera director, and industrial CGI specialist.

You are working inside the existing Claude project where the 3D digital twin of the fuel depot was developed.

Your task is to transform the existing project into a high-quality cinematic industrial video presentation that can be recorded and published on the official Instagram page of KTZ Freight Transportation — Center for Fuel Resources (CTR).

The user has provided:

1. The existing HTML project containing the 3D digital twin.
2. A visual reference image showing the desired cinematic style and presentation quality.

You must work directly with the existing project.

Do not create a new fuel depot. Do not rebuild the 3D model from scratch. Do not replace the existing infrastructure with fictional objects.

The existing project is the single source of truth for the depot's geometry, layout, objects, pipelines, and infrastructure.

---

1. MAIN OBJECTIVE

Implement a new feature inside the existing project:

CINEMATIC PRESENTATION MODE

This mode must automatically guide the virtual camera through the existing 3D scene and create a cinematic presentation of the fuel depot.

The presentation should showcase:

- The overall fuel depot infrastructure.
- Existing vertical and horizontal storage tanks.
- Above-ground pipelines.
- Underground pipeline networks.
- Pumping equipment and technological facilities.
- The movement of petroleum products inside pipelines.
- The railway loading rack and existing railway tank cars.
- The relationship between the depot's above-ground and underground infrastructure.

The final result should resemble a professional industrial CGI documentary or high-end corporate engineering visualization.

It must not look like a typical screen recording of a browser-based 3D model or a video game.

---

2. FIRST: ANALYZE THE EXISTING PROJECT

Before modifying any code, thoroughly inspect the current HTML file and its JavaScript implementation.

Identify:

- The 3D engine and rendering architecture.
- The existing scene, camera, renderer, and controls.
- The actual storage tank objects.
- Existing buildings and industrial structures.
- The actual pipeline geometry and network data.
- Existing underground infrastructure.
- Existing pumps, valves, and technological equipment.
- The railway rack and railway tank car models.
- Existing fluid-flow animation, if implemented.
- Existing lighting, materials, and rendering settings.
- The current application structure and UI controls.

Determine how the current project represents the real fuel depot.

Do not assume that every object or pipeline is technically complete. Verify the actual geometry and connectivity before using it in the cinematic sequence.

If any part of the model is uncertain, incomplete, or conditional, do not present it as verified real-world infrastructure.

The existing project must remain fully functional.

Preserve:

- The existing object positions.
- The dimensions and proportions of all infrastructure.
- The actual storage tank geometry.

Do not:

- Create fictional pipeline connections.

- Break the existing application.

The cinematic mode must be an additional feature, not a replacement for the existing application.

Create a backup of the original HTML file before making changes.

---

4. CINEMATIC CAMERA SYSTEM

Implement a dedicated cinematic camera controller using the existing camera and rendering system.

The camera must provide:

- Smooth cinematic movement.
- Natural acceleration and deceleration.
- Smooth camera transitions.
- Controlled camera rotation.
- Stable framing.
- Professional composition.
- Collision avoidance.
- No sudden jumps.
- No camera clipping through tanks, buildings, pipes, or the ground.

Use predefined camera paths based on the actual existing scene.

Do not use random camera movement.

Where possible, calculate camera positions and target points from the actual object coordinates and bounding boxes.

The camera must automatically frame the relevant object while maintaining an appropriate cinematic distance.

Add controls for:

- Start presentation.
- Pause.
- Resume.
- Stop.
- Restart.
- Skip to the next scene.
- Return to normal manual camera control.

When cinematic mode is stopped, restore the original camera position, controls, and application state.

5. CINEMATIC VIDEO STORYBOARD

Create a cinematic sequence approximately 55–60 seconds long.

The sequence must use the existing 3D scene and actual project objects.

Scene 1 — Aerial Establishing Shot

Duration: 0–6 seconds

Start with a high-angle overview of the fuel depot.

The camera slowly moves forward and descends toward the site.

Show the overall scale and layout of the existing infrastructure.

Use natural early-morning or golden-hour lighting.

The shot should establish the depot as a real industrial facility.

Scene 2 — Storage Tank Park

Duration: 6–13 seconds

Move the camera smoothly toward the existing storage tank area.

Perform a cinematic low-angle pass near the actual tanks.

Show:

- Tank shells.
- Roofs.
- Access ladders.
- Platforms.
- Existing pipe connections.
- Industrial details.

Use realistic metal materials, natural reflections, and soft shadows.

Do not modify the tank geometry or dimensions.

Scene 3 — Underground Infrastructure

Duration: 13–21 seconds

Transition smoothly into the underground network visualization.

Use the existing underground infrastructure mode if available.

Create a cinematic ground cutaway that reveals:

- Existing underground pipelines.
- Actual pipeline routes.
- Existing wells and underground structures.
- Soil layers.
- Connections between underground and above-ground infrastructure.

The ground should appear as a realistic technical cross-section.

Do not invent additional underground pipelines.

The transition between the surface and underground view must be smooth and visually clear.

Scene 4 — Pumping and Technological Equipment

Duration: 21–28 seconds

Move the camera toward the existing pumping equipment.

Show the actual pumps, valves, pipe connections, and technological components.

Use realistic industrial lighting and materials.

The equipment should appear substantial, technically credible, and physically present.

Do not add fictional machinery.

Scene 5 — Petroleum Product Flow Inside a Pipeline

Duration: 28–39 seconds

This is the most important scene of the entire presentation.

Move the camera close to an existing pipeline.

Create a cinematic technical cutaway that allows the viewer to see the petroleum product moving inside the pipe.

The liquid must:

- Remain inside the actual pipeline.
- Follow the existing pipeline route.
- Move continuously in the correct direction.
- Follow bends and connected sections.
- Pass through existing pipe connections.
- Maintain a realistic liquid appearance.
- Never flow through solid pipe walls.
- Never appear outside the pipeline.
- Never travel through disconnected pipe sections.

Use the existing fluid-flow system if one is already implemented.

If no suitable fluid animation exists, implement a visual fluid-flow effect based on the actual pipeline geometry and connectivity.

Do not create a separate fictional pipe just for the animation.

The liquid should have a physically plausible petroleum-product appearance: subtle amber, pale golden-brown, or appropriate natural fuel coloration.

Avoid neon colors, glowing liquid, magical effects, or exaggerated transparency.

Use realistic reflections and controlled highlights.

The camera should travel alongside the pipeline while the liquid moves through it, allowing the viewer to clearly understand the technological process.

Scene 6 — Railway Loading Infrastructure

Duration: 39–48 seconds

Move the camera toward the existing railway loading rack.

Show the actual railway tank cars, loading infrastructure, and connected technological equipment.

Use a smooth tracking shot along the railway infrastructure.

Preserve the actual geometry and arrangement of the existing railway objects.

Do not generate fictional railway equipment or alter the railway layout.

Scene 7 — Final Aerial Shot

Duration: 48–58 seconds

The camera smoothly rises and pulls back.

Reveal the overall fuel depot from a high cinematic angle.

The final shot should communicate the scale, complexity, and technological significance of the digital twin.

Leave sufficient visual space for a corporate title overlay during post-production.

Suggested final title:

“CTR — CENTER FOR FUEL RESOURCES”

“DIGITAL TWIN”

“Industrial infrastructure. Visualized.”

Do not generate or invent the official KTZ logo. Use the official logo asset if it is already available in the project or supplied separately.
