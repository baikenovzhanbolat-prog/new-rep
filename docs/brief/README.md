# Требования заказчика (обязательны для всей разработки)

Тексты заказчика, перенесённые в проект без изменения. Действуют для каждой задачи, каждого изменения кода
и каждого нового модуля. Краткая выжимка правил — в `CLAUDE.md` (раздел «Требования заказчика»).

| Файл | Что это |

| [01-postoyannye-instruktsii.md](01-postoyannye-instruktsii.md) | Постоянные инструкции: правила разработки, 17 разделов, приоритеты, главное правило |

| [03-rol-eksperta.md](03-rol-eksperta.md) | Роль: инженер-архитектор промышленных цифровых двойников (АСУ ТП, ПАЗ, СКАДА), стиль ответов |
| [04-kinorezhim-master-prompt.md](04-kinorezhim-master-prompt.md) | Мастер-промт кинорежима (англ.): раскадровка 55–60 с, 9:16, запись видео, критерии приёмки |

(порядок приоритетов — раздел 17 постоянных инструкций).

Анализ соответствия проекта этим требованиям и рекомендуемый порядок работ — `docs/analysis/`.
